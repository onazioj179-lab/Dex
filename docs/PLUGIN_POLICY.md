# DEX Plugin and Marketplace Policy

**Effective date:** 2026-05-06  
**Version:** 1.0.0  
**Contact:** onazi75@gmail.com

Plugins can make DEX more powerful, but they can also create security, privacy, reliability, and legal risk. This policy applies to plugin developers, plugin publishers, plugin users, and marketplace submissions.

## 1. Required Plugin Rules

Plugins must be honest about capabilities, permissions, data access, network use, paid features, and risks. Plugins must not contain malware, spyware, credential theft, hidden data exfiltration, illegal automation, safety bypasses, deceptive UI, trademark misuse, or policy-evading behavior.

## 2. Permissions and Data

Plugins must request only the permissions needed for their stated function. If a plugin accesses files, network endpoints, credentials, clipboard data, screenshots, browser data, AI/model features, or user content, it must clearly disclose that behavior before use.

## 3. Developer Responsibility

Plugin developers are responsible for their code, dependencies, data practices, security, licensing, support, payments, and compliance with law. Developers must comply with the DEX Terms, Privacy Policy, Security Policy, and all third-party licenses.

## 4. DEX Review and Removal Rights

DEX may review, reject, delist, quarantine, disable, remove, rate-limit, block, or restrict plugins, developers, accounts, or marketplace access when needed to protect users, DEX, rights holders, infrastructure, or the company.

## 5. User Responsibility

Users install plugins at their own risk and are responsible for permissions they grant. Users should review plugin permissions, publisher identity, network behavior, and data access before enabling a plugin.

## 6. Reporting Plugin Abuse

Report malicious, deceptive, infringing, unsafe, or policy-violating plugins to onazi75@gmail.com with the subject `[PLUGIN] DEX Plugin Report`.
