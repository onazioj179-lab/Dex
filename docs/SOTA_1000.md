# SOTA 1000 — Program Checklist

State-of-the-art program (~1000 items, crash-first). Full structure in the plan.
Conventions: reuse existing infra; new deps only where justified (xterm/pdfjs/qrcode);
stage only; no emojis; batch verify with `npm run lint` + `npm run build`; fail honestly.

Standing build rule: ship ONLY the universal NSIS installer `DEX-Setup-<version>.exe`.
Do NOT re-add per-arch / portable / zip targets or `-${arch}` in `build.nsis.artifactName`.

This tracker keeps OPEN work visible; completed items are condensed below so the
remaining surface is clear. Full per-item evidence lives in docs/REFINEMENT.md.
