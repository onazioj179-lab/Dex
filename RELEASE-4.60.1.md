# DEX 4.60.1 is out

- **Per-app focus modes** — hide chrome, mute notifications, dim background for any app you're focused on

- **Smarter cache + auto-pause** — uses less memory when idle, resumes when you need it
- **Prism brush improvements** — smoother, more stable drawing
- **Typography refresh** — updated fonts and spacing across the app
- **Small tile improvements** — better window positioning when you snap left/center/right
