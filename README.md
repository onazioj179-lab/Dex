# DEX -- Personal Control Hub

> Created by Onazi Treasure OJ &lt;onazi75@gmail.com&gt; - Version 3.8.9 - Copyright (c) 2026 - DEX Software License Agreement v1.0

DEX is your personal command bar for the desktop. One key, one bar, anything done.
Take notes, run timers, open files, snap a screenshot, focus your screen, mute the
room, jump between apps -- without ever leaving the keyboard. Everything happens on
your machine.

## Why people use DEX

- **One assistant for everything.** Tap UKI, type what you want, get it done. No
  menu hunting.
- **Plans you can preview.** Anything risky is shown to you first as a clear list
  of steps. You hit Run or Cancel.
- **Apps that work together.** Notes, Tasks, Files, Workflows, Vinx, Axl, Rewind
  and more share context, so your work follows you.
- **Yours, on your machine.** Patterns, history, and shortcuts stay on this
  device. Optional cloud sync. Optional analytics, off by default.
- **Built for keyboards.** Every action has a shortcut. Press `/` for the
  command menu, `Ctrl+K` for the launcher, `Ctrl+Space` for UKI.
- **Always improving.** Free updates roll in. New things to try every release.
