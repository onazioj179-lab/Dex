## Release blockers by area

- **Applications and Settings.** The real desktop registry supplies the application picker. DEX app windows support a theme override, reduced motion, a maximized launch preference and custom opening dimensions. Browser, Notes, Gallery and DexCode provide additional persistent controls. Native window frame behavior, file associations, notification controls and the broader UKI permission audit remain open.
- **Audio.** Windows uses documented Core Audio playback devices and sessions. Output switching and app routing are handed off to Windows Sound and Volume Mixer. Verify built-in, wired and Bluetooth devices, simultaneous applications, device changes, disconnection and reconnect. Implement supported Linux and macOS adapters. WebView-backed apps can share an operating-system audio session.
- **Windowing and spatial workspace.** The current shell uses app-keyed floating windows. Verify live spatial rendering and interaction with Browser, Notes, Files and GPU-heavy creative apps, including viewport changes during drag and resize. Independent document-window identities, unsaved work protection and workspace recovery still need end-to-end coverage.
- **Ledger and Bioengineering.** Neither is an installed desktop launch target in the audited registry. Ledger still needs a verified local-first transaction model with accurate monetary arithmetic and import deduplication. Bioengineering still needs a launchable application and validation of scientific data tooling with suitable datasets.
- **UKI and Umari.** Source changes add native approved-folder indexing, incremental file updates, cancellation, foreground context controls, and permission-gated filename retrieval. Verify native dialogs and filesystem events in the packaged app on each supported host. Extend project relationships, custom child-folder exclusions, and authorized context beyond the registered surfaces.
- **Desktop performance.** Run comparable before-and-after package measurements for startup, windowing, Browser, files, Gallery, creative exports and UKI. Collect working set, CPU and frame times in a repeatable host configuration.
- **Release.** Reverify upgrade and rollback on the final signed candidate. Rollback with the previous installer, elevated installs, other Windows accounts and physical audio testing remain open. See [DEX 7.0.2 verification](DEX_7.0.2_VERIFICATION.md).
