## DEX 7.0.3 (001y)

Bug fixes and improvements to everyday work across DEX.

- Improved App Menu search, file navigation, and the Now panel.
- Activity records work across Notes, Files, and Tasks. Open an entry to return to its item.
- More consistent controls and list styling in light and dark mode.
- Fixed Screen Recorder cancellation and capture cleanup.
- Improved QR Code, Prism, DEX Code, Terminal, and Umari folder workflows.
- Fixed Unix-style command flags and pipeline input in Windows PowerShell.

This build uses version 7.0.3. Existing 7.0.3 installations require a manual install of this build.
