## DEX 7.0.3

This update brings a Dock you can place anywhere, a cleaner Software Update with the option to go back to an earlier version, and backups you control.

**Dock**
- Drag the Dock anywhere, or pull it straight out of the screen edge.
- The Dock no longer slides away while you are using it.
- A shorter menu: Expand, Auto-collapse, Auto-hide.

**Software Update**
- Automatic updates: DEX checks once a day and tells you when a new version is out.
- Go back to an earlier version from Software Update. Your data is backed up first.

**Backups**
- Back up your DEX data from Settings › Storage, keep daily automatic backups, and restore any of them.

**Also in this update**
- Faster start-up: less code loads before the desktop appears.
- Menus and tooltips no longer show keyboard shortcut text.
- Browser privacy (Tor or a proxy, tracking protection), multi-finger gestures, and improvements to Media, Maps, Ledger, Bio and AXL.
